Mafsil connects an MCP-compatible agent to a chosen workspace on Windows or Linux.

This first release offers read-only file inspection by default, with separately enabled conditional file edits and command execution. Nine composable tools cover files, process sessions and native terminals.

## Included

- MCP `2026-07-28` and four earlier protocol revisions through the official Go SDK.
- Bounded file reads, images and embedded resources with complete-file SHA-256 revisions.
- Exact conditional edits, file creation/moves/deletion, prevalidation and rollback for ordinary IO failures.
- Windows Job Objects and ConPTY; Linux process groups and PTY.
- Bounded output replay, cancellable stdin, timeouts, terminal resize and approximate screen snapshots.
- Per-user terminal installation, verified downloads, rollback-capable updates and conservative uninstall.
- Original editable Mafsil branding and Windows executable icon/version resources.

## Assets and installation

Choose Windows amd64, Linux amd64 or Linux arm64. Runtime binaries do not require Go. The `install.ps1` and `install.sh` assets detect the platform and check the release's `SHA256SUMS`. See `docs/installation.md` for commands, offline bundles and removal.

`BUILD-INFO_*` and `DEPENDENCIES.json` record the build inputs. SHA-256 checksums detect corrupted or mismatched downloads; binaries are not independently code-signed.

## Compatibility and limits

- Windows shell tools use PowerShell 7 and ConPTY-capable Windows. Linux shell tools use Bash and `/dev/ptmx`.
- Stdio is the built-in transport. Secure MCP Tunnel is an optional external-client integration; live tunnel/account connectivity has not been tested by this project.
- Command execution is disabled by default and is not a sandbox. Enabled commands have the account's filesystem and network authority.
- File transactions are not crash-atomic or coordinated with external writers. Reread after a cancelled mutation.
- Linux deliberately detached descendants can escape process-group cleanup.
- Terminal snapshots approximate common VT behavior; full grapheme widths, terminal queries and rich graphics are not emulated.
- The API is pre-1.0; review the changelog before upgrades.
