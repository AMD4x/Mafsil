## 🚀 Your workspace. Connected.

Meet **Mafsil**: an MCP server that brings files, commands and interactive terminals into your agent's workflow on **Windows and Linux**.

The first public release gives you nine focused tools to inspect a workspace, apply precise edits, run commands and keep terminal sessions going — with explicit control over the capabilities you enable.

## ✨ What you can do

- **Work with files precisely.** Read text, images and resources; create, edit, move or delete files using SHA-256 revision checks and rollback for ordinary IO failures.
- **Keep commands connected.** Run commands and interactive shells, send input, resize terminals, replay bounded output and inspect screen snapshots.
- **Use native terminals.** Windows uses Job Objects and ConPTY; Linux uses process groups and PTY.
- **Connect through MCP.** Use compatible stdio clients with MCP `2026-07-28` or four earlier protocol revisions supported by the official Go SDK.
- **Install and update deliberately.** Platform installers verify downloads, preserve unrelated files and provide status, update and uninstall commands.

### Built and checked on all three platforms

Native Windows amd64, Linux amd64 and Linux arm64 CI covers Go tests, race detection, static and vulnerability checks, packaged CLI/MCP behavior, and installer/rollback fixtures. The release publishes the reviewed CI artifacts, with an approved SHA-256 manifest binding their exact bytes.

`SHA256SUMS`, `BUILD-INFO_*` and `DEPENDENCIES.json` accompany the downloads. Binaries are **not independently code-signed**; checksums detect corruption and mismatched files, not a compromised publishing account.

### Before you enable execution

- File inspection is available by default. Enable file changes and command execution separately for a trusted client. Commands run with your account's authority; Mafsil is not an execution sandbox.
- Windows shell tools require PowerShell 7 and ConPTY-capable Windows. Linux shell tools require Bash and `/dev/ptmx`; the installer requires the GNU utilities listed in the installation guide.
- File edits and installer updates recover from ordinary failures, but are not crash-atomic. Reread files after a cancelled mutation. Deliberately detached Linux descendants can escape process-group cleanup.
- Terminal snapshots approximate common VT behavior; full grapheme widths, terminal queries and rich graphics are not emulated.
- Secure MCP Tunnel is an optional external-client integration. Live tunnel/account connectivity has not been validated by this project.
- This is a **pre-1.0 API**. Review the changelog before upgrading.
