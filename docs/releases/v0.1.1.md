## 🚀 Your workspace. Connected. Updated.

Meet **Mafsil v0.1.1**: a maintenance release focused on safer native binaries, current dependencies and an easier installation experience on **Windows and Linux**.

This release keeps the same nine MCP workspace tools and explicit read-only-by-default capability controls. It updates the toolchain, strengthens release verification and makes installation and updates more consistent — without changing the MCP tool interface.

## ✨ What's improved

- **Patched Go runtime.** Rebuilt the Windows x64, Linux x64 and Linux ARM64 binaries with **Go 1.27.3**, addressing vulnerabilities reported against the previous Go 1.27.0 standard library.
- **Updated dependencies.** Upgraded `golang.org/x/sys` from **v0.48.0** to **v0.49.0**, with the matching third-party license notice.
- **Refreshed CI tooling.** Updated Staticcheck to **v0.8.2**, `actions/setup-python` to **v7.1.0**, `actions/upload-artifact` to **v7.0.2** and `actions/download-artifact` to **v8.0.2**.
- **Simpler install and update.** One-command bootstrap scripts select the latest stable release, verify the release installer and preserve existing configuration, scratch files and chosen workspace.
- **Stronger release checks.** Native CI tests the bootstrap, packaging, protocol behavior, installer rollback and security checks. Version-aware distribution tests now follow the repository's `VERSION` file.

**Windows — PowerShell 7**

```powershell
irm https://raw.githubusercontent.com/AMD4x/Mafsil/main/install.ps1 -ErrorAction Stop | iex
```

**Linux — Bash, x64 / ARM64**

```bash
(set -o pipefail; curl --proto '=https' -fsSL https://raw.githubusercontent.com/AMD4x/Mafsil/main/install.sh | sh)
```

Close any MCP client using the old binary before updating. Re-running the same command updates the executable and managed files while leaving your configuration and workspace intact. For a fixed version or an offline bundle, see the [installation guide](https://github.com/AMD4x/Mafsil/blob/v0.1.1/docs/installation.md).

### Built and checked on all three platforms

Native **Windows amd64**, **Linux amd64** and **Linux arm64** CI covers Go tests, race detection, Staticcheck and vulnerability scans, packaged CLI/MCP behavior, bounded fuzzing and installer/rollback fixtures. Publication verifies the selected build artifacts and their SHA-256 manifest, then exercises public HTTPS installation on all three targets.

`SHA256SUMS`, `BUILD-INFO_*` and `DEPENDENCIES.json` accompany the downloads. Binaries are **not independently code-signed**; checksums detect corruption and mismatched files, not a compromised publishing account.

### Before you enable execution

- File inspection remains available by default. Enable file changes and command execution separately for a trusted client. Commands run with your account's authority; Mafsil is not an execution sandbox.
- Windows shell tools require PowerShell 7 and ConPTY-capable Windows. Linux shell tools require Bash and `/dev/ptmx`.
- File edits and installer updates recover from ordinary failures, but are not crash-atomic. Reread files after a cancelled mutation. Deliberately detached Linux descendants can escape process-group cleanup.
- Terminal snapshots approximate common VT behavior; full grapheme widths, terminal queries and rich graphics are not emulated.
- Secure MCP Tunnel remains an optional integration. Live tunnel/account connectivity has not been validated by this project.
- This remains a **pre-1.0 API**. Review the [changelog](https://github.com/AMD4x/Mafsil/blob/v0.1.1/CHANGELOG.md) before upgrading.
